# Public release provenance

Version 0.2.1 is the first public release of Inferential Safety Lab at
<https://github.com/aldaqrouqtaysir/inferential-safety-lab>.

The public mirror was prepared from an explicitly allowlisted source tree. It
begins with one honest initial public-release commit, not a simulated or
backdated development history. Private repository metadata, private planning
notes, caches, coverage output, environments, and migration-working documents
are not part of the mirror.

Selected implementation ideas originated in an earlier project by the same
author and were adapted into this bounded educational product. The earlier Git
history, result artifacts, decisions, reports, and terminal evidence were not
copied. This repository does not convert or restate that earlier project's
outcome as a successful finding.

The scientific release boundary is protected by deterministic tests. The frozen
default demonstration contains 184 numeric leaves with SHA-256 fingerprint
`ab232be3ea0d25ceb4e1459be82ac34760237d565df875aea89250a869a905aa`.
Version 0.2.1 refines visual identity, presentation hierarchy, screenshots, and
browser assertions on top of the V0.2 product architecture. It does not change
scientific equations, random streams, scenarios, estimators, metrics,
denominators, failure rules, or numeric results.
