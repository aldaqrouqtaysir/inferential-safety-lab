# Two-to-three-minute demonstration script

## 0:00-0:30 | Understand

Open **Understand**. Explain that the simulator creates data with a known answer,
introduces a controlled data problem, applies several analysis approaches, and
compares accuracy, usable uncertainty, withheld results, failures, and data
changes. Read the compact scientific boundary.

## 0:30-0:55 | Set up the experiment

Select **Set up an experiment**. Keep **Randomly missing measurements** and
**Quick, recommended**. Point out the MCAR explanation, 60% intensity, runtime
estimate, collapsed Advanced settings, and collapsed generated-data preview.

## 0:55-1:20 | Run

Select **Run experiment**. Read the progress sequence: preparing synthetic
samples, simulating each sample, summarizing the comparison, and completion.
Open **Results**.

## 1:20-1:55 | Read the primary comparison

Start with the immutable run summary and the selected finding. Explain that a
method can appear accurate only on the datasets where it reports. Compare usable
uncertainty, estimate error, the four method summaries, and data changed or
discarded.

## 1:55-2:20 | Reported and withheld

Show the reported, withheld, or failed chart. The minimum-evidence rule reports
43 results and withholds 117 because the rule was not satisfied. Emphasize that
withholding can be intentional safety behavior.

## 2:20-2:45 | Exact record

Open **Technical details and exact records** to show formulas, exact
denominators, method contracts, the replay command, environment-specific run
fingerprint, and canonical JSON. Close it, prepare the **Inferential Safety
Card**, and explain that the card is a self-contained audit-ready record.

Finish by using **Change settings** and **Start another experiment** so the
visitor sees how to revise or restart the workflow.
