# Project history

Inferential Safety Lab reuses selected, independently tested software
components developed during an earlier simulation study. That study’s terminal
result was negative and remains documented in its original repository. This
repository presents the reusable software as a separate tool and does not
restate the earlier study as a successful or publication-grade finding.

The new repository began with no copied Git history and no remote. The public
checkout now permits only a credential-free GitHub HTTPS or SSH remote; local,
file, user-home, credential-bearing, historical N3, and unapproved-host remotes
remain forbidden by privacy tests. Its scope, terminology, configuration,
failure model, method panels, UI, CLI, metrics, reports, documentation, and
tests are purpose-built for the bounded educational product. Version 0.2.1 is
the first public pre-release candidate; no release tag exists yet.
